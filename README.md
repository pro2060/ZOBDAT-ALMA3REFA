# زبدة المعرفة — نسخة أولية قابلة للتثبيت

## ما تتضمنه النسخة
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- مكتبة أولية: «سيكولوجية المال» و«زغازيغ».
- صفحات ملخصات وأفكار قابلة للحفظ.
- دفتر ملاحظات محلي على الجهاز.
- قراءة صوتية للملخص باستخدام محرك النطق في المتصفح (ليست ملفات صوتية مسجلة).
- دعم PWA والتشغيل دون اتصال بعد أول تحميل.

## التشغيل
1. ارفع محتويات المجلد إلى مستودع GitHub.
2. فعّل GitHub Pages من Settings → Pages واختر فرع النشر ومجلد الجذر.
3. افتح رابط الموقع عبر HTTPS من الهاتف.
4. من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» أو استخدم زر «تثبيت التطبيق» إذا ظهر.

## ملاحظات
- البيانات محفوظة محلياً في متصفح الجهاز عبر localStorage؛ لا توجد مزامنة بين الأجهزة في هذه النسخة.
- لا توجد حسابات مستخدمين أو قاعدة بيانات سحابية بعد.
- الخط الخارجي قد يحتاج اتصالاً بالإنترنت أول مرة؛ بقية ملفات التطبيق مخزنة مؤقتاً.
- الملخصات هنا نموذج أولي تحريري وليست بديلاً عن نص الكتاب الأصلي.
