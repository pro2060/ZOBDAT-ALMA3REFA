# زبدة المعرفة — الدفعة الأولى

تضم هذه الحزمة الملفات المنظمة للكتب الخمسة الأولى.

## هيكل الملفات
- `books/`: ملخصات Markdown قابلة للتعديل.
- `audio_scripts/`: نصوص مستقلة للتسجيل أو التحويل إلى صوت.
- `manifest.json`: فهرس الدفعة وبيانات الكتب.

## تنبيه بخصوص الصوت
الموجود في هذه الحزمة نصوص صوتية جاهزة، وليست ملفات MP3 مسجلة. لم يتم إنشاء صوت اصطناعي أو ملف صوتي فعلي في هذه الدفعة.

## طريقة الإضافة إلى مستودع GitHub الحالي
انسخ مجلدي `books` و`audio_scripts` وملف `manifest.json` إلى جذر المستودع الحالي `pro2060/ZOBDAT-ALMA3REFA` مع الحفاظ على الملفات الموجودة. لا تستبدل `index.html` أو `app.js` في هذه الخطوة.

## منهجية المحتوى
هذه ملخصات تفسيرية أصلية وليست بديلاً عن قراءة الكتب. تم تجنب نقل نصوص مطولة من الكتب. مساحة الملاحظات الشخصية والعائلية متروكة فارغة عمداً.
